The action control — uppercase, letterspaced, 6px corners, never a pill.

```jsx
<Button variant="primary" iconLeft="phone">Reserve a table</Button>
<Button variant="secondary" size="lg" iconRight="arrow-right">Order online</Button>
<Button variant="onDark">View menu</Button>
```

One primary per view. `secondary` (gold) is for delivery/ordering CTAs; `onDark` is the only variant to use on the maroon field. Hover lightens, press nudges 1px down — no scaling.
