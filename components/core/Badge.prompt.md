Uppercase micro-label for dish status: Signature, Chef's special, Chettinad, Spicy, Veg.

```jsx
<Badge tone="gold" variant="solid">Signature</Badge>
<Badge tone="spicy" icon="flame">Spicy</Badge>
```

Never more than two badges on a menu row. Dietary veg/non-veg status uses `DietDot`, not a badge.
