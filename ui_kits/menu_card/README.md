# UI kit — printed menu card

Three A4 pages (794×1123 at 96dpi) built from the same `MenuSection` / `MenuItemRow` primitives as the website, so a price change in `data/menu.json` updates both.

- Emblem centred, script wordmark, Tamil sub-line, gold ornament — the fascia board arrangement.
- Dotted leaders between dish and price; diet dots in the left column.
- No add buttons in print (`onAdd` omitted); footer carries the address and page number.

**Source:** `uploads/Hotel Mudaliyar Menu_Final Rev.xlsx`, sheet 1, verbatim names and prices (79 items). Tamil section titles were added by transliteration of the English section names — **please review them**; only the fascia board's Tamil ("ஹோட்டல் முதலியார்", "அம்மையப்பன் ஹால்") is source-verified.
